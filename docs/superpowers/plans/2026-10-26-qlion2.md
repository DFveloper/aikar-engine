# QLion2 Implementation Plan

Goal: retain QLion's old-momentum RMS adaptive LR and quantized state, with a mandatory 32-element unit and fused group statistics on CPU/CUDA.

Design: add a distinct optimizer enum and CLI name, reuse all QLion graph and update paths. Encode fused group scaling as internal parameter unit -32. Compute old-momentum RMS before updating momentum, with the existing alpha * RMS / (RMS + tau) rule and zero/nonfinite handling. Q2_0 weights span two independent 32-element groups. No FP32 group statistics tensor for fixed tau. For optional layer-RMS warmup, use a compact 9-float result and existing two-float persistent state; CUDA reduces directly from Q8 momentum into shared memory. Keep original QLion modes unchanged.

Alternatives considered: retaining the standalone group-statistics pass wastes DRAM; duplicating update kernels would duplicate quantization/residual logic. Reusing update helpers with fused reductions avoids both.

Constraints: preserve pre-existing working-tree changes, use a separate build directory, do not commit/push, retain learning stability and checkpoint compatibility checks. User delegated implementation choices and autonomous execution. This is the AIKAR fork. No ADENTS.md found in the scoped instruction search; AGENTS.md read.
